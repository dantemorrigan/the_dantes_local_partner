# Handoff / статус работы

Живой файл для того, кто продолжит работу (человек или ИИ). Обновлять при каждом коммите.

## Окружение
- Java 25 (в облачной сессии: `/opt/jdk/jdk-25.0.5+8`), Gradle wrapper 9.8.2, Loom 1.19, MC 26.1.2 (без обфускации, имена Mojang).
- Исходники MC для справки: `./gradlew genSources` или распаковать `*-sources.jar` из `.gradle/loom-cache`.
- Совместимость: собрать The Dante's Infinity и положить jar в `libs/` (в git не попадает). Репозиторий Infinity **не менять**.
- Тест: `LIBGL_ALWAYS_SOFTWARE=true xvfb-run -a ./gradlew runClientGameTest` → скриншоты в `build/run/clientGameTest/screenshots/`.
  Сценарий: `src/gametest/java/.../PartnerTest.java` (язык клиента ru_ru, суперплоский мир).

## Проверено в реальном клиенте (PartnerTest, весь сценарий зелёный)
- [x] Пауза → «Local Partner…» → панель → позвать; удаление с подтверждением, вещи переходят игроку.
- [x] Колесо на C: вёрстка без наложений на узком экране (854×480), стрелки + Enter.
- [x] Плашка HUD: текст в пределах плашки, поднимается над чатом, пока видны сообщения.
- [x] Рубка (с крафтом деревянного топора), пересадка саженцев, доставка бревен игроку.
- [x] Руда: крафт кирки из бревен, добыча открытого угля.
- [x] Бой с зомби, автонадевание брони, помощь едой (только если у игрока нет еды), «Держи: Хлеб ×3».
- [x] Телепорт при отставании, Незер туда-обратно (через stash/restore, ждёт безопасную точку).
- [x] Infinity: ждёт снаружи White Void и возвращается.

## Добавлено после последнего прогона теста (только компиляция, тестирует пользователь)
- [ ] Щит в левой руке (поднимает между ударами), лук со стрелами для летающих/недоступных целей.
- [ ] Рецепты щита, лука, стрел в режиме «Свободен».
- [ ] Сбор вещей игрока после его смерти → отдельный мешок `ownerLoot` → отдаёт после возрождения.
- [ ] Факелы рядом с игроком в тёмных пещерах.

## Не проверено
- [ ] Выход/вход в мир (stash при отключении), смерть напарника и возрождение через 30 с.
- [ ] Режим «Свободен» (AutoJob) на длинной дистанции, лестница вниз в обычном мире.
- [ ] Мультиплеер (2 игрока, у каждого свой напарник), выделенный сервер.

## Известные риски / идеи
- Пользователь просил не гонять много тестов — тестирует сам; достаточно `./gradlew build`.
- `PartnerTest` ждёт 180 с на дерево; если медленно — смотреть `brain.debug()` в тексте ошибки.
- Лестница вниз на суперплоском мире упирается в бедрок — для руды в тесте ставится открытый уголь.
- Дальше по плану: лук/щит, установка верстака/печи в мире, сон, укрытие, Незер/Край.
